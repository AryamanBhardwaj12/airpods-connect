# Changes

## v0.2.0 - first public release

- One-click connection to an exact paired AirPods device on Windows x64.
- Runtime-included and small setup packages, with per-user startup and guarded uninstall.
- V2 launchers isolate Windows PowerShell module discovery from inherited PowerShell 7 paths.
- Setup saves a local error log and detects incomplete ZIP extraction.
- No paired-device settings or local troubleshooting history included.
